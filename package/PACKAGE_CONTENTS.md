# 内容と除外範囲

含む：空の記憶テンプレート、汎用運用説明、導入スクリプト、
SessionStartアダプター、隔離fixtureを使うテスト、整合性ハッシュ。

含まない：元ユーザーのプロフィール・行動指針・所在地・PC情報・個人パス、
会話全文・要約・作業経過・実際の決定履歴・実機検証記録、
過去のHOT_STATE・adapter.log・config.toml・信頼登録・APIキー・資格情報。
元環境の要件書・設計書・実装記録・検証記録も含みません。

canonical/policy.mdを含む全記憶ファイルは空の開始テンプレートです。
index.md等の汎用ルールは補助記憶の利用手順であり、元ユーザーの記憶ではありません。
テスト中のfixture state・test-session・架空パスは合成試験データです。

INSTALL.ps1は対象プロジェクトに合わせてHookを生成します。
本版は元ホストのconfig.tomlハッシュを持たず、導入時にも記録しません。
PACKAGE_SHA256SUMS.txtは配布ファイルの整合性一覧です。
